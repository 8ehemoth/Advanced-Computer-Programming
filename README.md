# 고급컴퓨터프로그래밍

강원대학교 고급컴퓨터프로그래밍 수업에서 학습한 C언어 개념과 실습·과제 코드를 정리한 저장소입니다.

C언어의 기본 문법을 익히고, 문제의 처리 과정을 코드로 작성한 뒤 실행 결과를 확인하며 프로그래밍 기초를 쌓았습니다.

## 학습 목적

- C언어의 기본 문법과 프로그램 구성 이해
- 문제의 입력·처리·출력 흐름을 코드로 표현
- 실습과 과제를 통한 프로그램 작성 연습
- 실행 결과를 확인하며 오류를 찾고 수정하는 과정 경험

## 학습 및 실습 방식

수업에서 배운 개념을 예제와 과제에 적용하고, 입력값에 따라 프로그램이 어떻게 동작하는지 확인했습니다.

코드를 작성하는 것뿐 아니라 실행 순서와 데이터의 변화를 따라가며, 예상한 결과와 실제 출력이 다른 부분을 살펴봤습니다.

## 저장소 내용

- 수업에서 다룬 예제와 실습 코드
- 과제 수행 과정에서 작성한 코드
- C언어 개념과 코드 동작에 대한 학습 메모

수업 예제와 직접 작성·수정한 코드가 함께 포함되어 있습니다. 각 자료는 해당 주제의 학습 과정을 기록하기 위한 목적으로 정리했습니다.

## 사용 언어

- C

## 학습을 통해 익힌 점

문제를 코드로 옮기기 전에 입력과 처리 조건, 출력 결과를 먼저 정리하는 습관을 익혔습니다.

또한 실행 결과가 예상과 다를 때 코드의 흐름과 변수값을 확인하며 원인을 찾는 연습을 했습니다. 이 수업에서 배운 C언어 기초를 이후 MCU 제어와 자료구조 학습에 활용했습니다.
